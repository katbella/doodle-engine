# Doodle Studio

The desktop editor for [Doodle Engine](https://doodleengine.dev), a narrative RPG engine for text-based, story-driven games.

Studio creates projects, edits game content through visual controls or a source editor, imports images, audio, and video, plays through dialogue branches with full control of game state, previews the game as a player sees it, and builds the files you publish.

This package is not published to npm. Download the installer from the [latest release](https://github.com/katbella/doodle-engine/releases/latest), or run it from a clone of this repository:

```bash
yarn install
yarn studio
```

Studio and the command line work on the same project files, so a project never belongs to one of them.
